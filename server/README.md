# РКГДTUBE stream

Маленький сервер, через который сайт показывает видео **из Telegram-канала @RCGDTUBE** своим плеером —
без YouTube и без VPN у зрителя.

Сервер входит в Telegram (лучше запасным аккаунтом), по номеру поста находит видео и отдаёт его
кусочками — перемотка работает сразу, файлы нигде не хранятся.

## Где запускать
Нужен свой сервер (VPS) **за границей** (Telegram в России блокируют) и **не за Cloudflare**
(его в России режут). Хватит самого маленького: 1 ядро, 1 ГБ памяти, Ubuntu 22.04/24.04.

## Установка — одна команда
В консоли сервера под root:

```
curl -fsSL https://raw.githubusercontent.com/mefix23/rcgdtube/main/server/install.sh | bash
```

Скрипт спросит `api_id` и `api_hash` — их бесплатно выдаёт https://my.telegram.org → API development tools.
В конце он покажет адрес сервера и ссылку для входа в Telegram (QR-код).
Адрес сервера вписывается на сайте в `assets/config.js` → `streamUrl`.

Обновить сервер до свежей версии — запустить ту же команду ещё раз.

## Адреса
| Адрес | Что отдаёт |
|---|---|
| `/` | проверка: `{"ok": true, "authorized": true}` |
| `/info/<пост>` | есть ли в посте видео, размер, длительность, разрешение |
| `/v/<пост>` | само видео (с перемоткой) |
| `/thumb/<пост>` | превью из Telegram |
| `/setup?key=…` | первый вход в Telegram по QR-коду |
