# РКГДTUBE

Сайт в стиле YouTube с ворками креаторов Geometry Dash из Telegram-канала [@RCGDTUBE](https://t.me/RCGDTUBE).

## Откуда берутся видео

1. **SQL-база создателя канала** — [kilor231/rcgdtube-bd](https://github.com/kilor231/rcgdtube-bd), файл `gdchannels.db`.
   В ней только ворки с YouTube, без пересылок из других каналов. База обновляется сама раз в час.
2. **Видео от админов** — их добавляют через страницу `upload.html` по ключу. Хранятся в
   [mefix23/rcgdtube-uploads](https://github.com/mefix23/rcgdtube-uploads) (`uploads.json`).

Каждые 15 минут GitHub запускает `scripts/build_data.py`: он скачивает базу, добавляет видео админов,
узнаёт названия с YouTube и сохраняет всё в `data/posts.json`. Сайт читает этот файл.
Превью и плеер берутся прямо с YouTube, поэтому картинки и видео здесь не хранятся.

## Страницы

- `index.html` — сам сайт: лента, поиск, страница видео, страница автора.
- `upload.html` — админка: вход по ключу, добавить видео, скрыть видео, удалить.
- `setup.html` — для владельца: подключить токен GitHub к админке (раз в год) и отключать ключи.

## Как устроены ключи

Ключей 30. Сами ключи нигде не хранятся. В `rcgdtube-uploads/config.json` для каждого ключа лежит
зашифрованный им «мастер-код», а мастер-кодом зашифрован токен GitHub с правом записи только
в `rcgdtube-uploads`. Поэтому без настоящего ключа записать что-то на сайт нельзя, а основной
репозиторий сайта токен изменить не может.

## Бот для Telegram-канала

`scripts/post_to_tg.py` выкладывает в канал видео, которые админы добавили на сайт (из базы канала ничего
не дублирует). Формат: название — by ник [ORIGINAL], описание цитатой, хэштеги, ссылка «СМОТРЕТЬ НА САЙТЕ».
Настройки в Settings → Secrets and variables → Actions: секрет `TELEGRAM_BOT_TOKEN` и переменная
`TELEGRAM_CHAT_ID` (`@имя_канала`). Бот должен быть админом канала с правом публиковать сообщения.
Что уже выложено, хранится в `data/tg_posted.json`.
