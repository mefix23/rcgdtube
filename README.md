# РКГДTUBE

Сайт как YouTube для ворков креаторов Geometry Dash из Telegram-канала [@RCGDTUBE](https://t.me/RCGDTUBE):
главная, Shorts, аккаунты через Telegram, лайки, комментарии, подписки, история, заявки через плюсик и модерация.

## Из чего состоит

- **GitHub Pages** — сам сайт (`index.html`, `assets/`). Каждые 15 минут GitHub запускает `scripts/build_data.py`
  и `scripts/post_to_tg.py` (расписание в `.github/workflows/update.yml`).
- **SQL-база создателя канала** — [kilor231/rcgdtube-bd](https://github.com/kilor231/rcgdtube-bd): ворки с YouTube из канала.
- **Supabase** — аккаунты, лайки, комментарии, подписки, история, заявки, модерация и хранилище видеофайлов.
  Схема базы: `supabase/schema.sql`. Серверные функции: `supabase/functions/tg-login` (вход через Telegram)
  и `supabase/functions/tg-bridge` (комментарии между сайтом и Telegram).

## Роли

- **Зритель** — входит через Telegram, ставит лайки, пишет комментарии, подписывается, отправляет видео через плюсик.
- **Модератор** — вводит код модератора в профиле (каждый код срабатывает у одного человека).
  Видит раздел «Модерация»: заявки с кнопками «Выложить» и «Отказать», скрытие любых видео, удаление комментариев.
- **Владелец** — вводит код владельца. Видит раздел «Команда»: кто какой код занял, отключение модераторов,
  подключение комментариев Telegram.

## Настройки

- `assets/config.js` — адрес Supabase, публичный ключ и ник бота для входа.
- Секреты Supabase (Edge Functions → Secrets): `TELEGRAM_BOT_TOKEN`.
- Секреты GitHub (Settings → Secrets and variables → Actions): секрет `TELEGRAM_BOT_TOKEN`, переменная `TELEGRAM_CHAT_ID`.
- Бот: в @BotFather командой `/setdomain` указать `mefix23.github.io` (нужно для кнопки входа).

## Бот для канала

Выкладывает в канал видео, которые прислали зрители и одобрили модераторы. Формат: название — by ник [ORIGINAL],
описание цитатой, хэштеги, ссылка «СМОТРЕТЬ НА САЙТЕ». Свои файлы уходят самим видео. Что уже выложено — `data/tg_posted.json`.

## Комментарии из Telegram

Включаются, когда владелец канала добавит бота админом в группу комментариев канала, а владелец сайта нажмёт
«Подключить комментарии Telegram» в профиле. Работает для постов, вышедших после этого.
