Подключение админки

Это нужно сделать один раз (и потом раз в год, когда закончится срок токена). Обычным админам эта страница не нужна.

Шаг 1. Создай токен на GitHub

  1. Открой страницу создания токена. Название, срок и права там уже заполнены.
  2. В блоке Repository access выбери Only select repositories и отметь rcgdtube-uploads. Только его, другие не нужны.
  3. Внизу нажми Generate token и скопируй токен (начинается с github_pat_).

Шаг 2. Вставь токен и любой ключ админа

Токен никуда не отправляется, кроме самого GitHub. На сайте он хранится только в зашифрованном виде, расшифровать его можно лишь ключом админа.

Ключи админов

Если ключ попал не к тому человеку, отключи его. Если отключённый ключ мог успеть войти, сделай ещё и новый токен (шаг 1–2), старый удали на GitHub.
